## 파이프라인
```
.rep ─► uranium-replay::parse (헤더·플레이어·종족·맵·명령 스트림)
     ─► 필터 (1v1, 테란 포함, APM≥80, 길이≥5분, 중도 이탈 제외(= 길이 5분 미만 제외, 2026-10-16 사용자 확인), 맵 각 축 ≤128 타일(030-R6), 맵 해시 집계)
     ─► (SC:R 포맷이면) 1.16.1 명령 형식으로 변환 (040-R10)
     ─► OpenBW 재생 (011 재생 모드, 테란 시점 RawFrame + PrivilegedSummary)
     ─► 명령 정렬: 프레임 f의 사람 명령(select+order) → 의미 단위 액션(031·034 역변환), delay = 다음 액션까지 프레임, 32 초과 구간은 NoOp(031-R11)
     ─► shard 저장 (판단 시점의 RawFrame + PrivilegedSummary + 레이블, zstd 압축, 게임 단위)
학습 시: shard 로드 ─► feature·마스크 추출(030, 034) ─► 대칭 증강(030-R4) ─► BC (041)
```

## Shard 포맷
```
shard_XXXXX.bin.zst
  header: schema_version, feature_version, action_version
  games[]: { meta{map_hash, map_family, matchup, player_race, perspective_slot, apm, result, src, stage},
             game_info,                                        // 010 GameInfo(static_map 포함), 시점 플레이어 기준
             steps[]{raw_frame, privileged, action_label} }   // feature·마스크는 학습 시 생성 (040-R12)
```
- `game_info`는 feature 추출(030)의 정적 맵 채널과 `MapInfo`에 쓴다. 추가하면서 `schema_version`을 올렸고, 이전 버전 shard는 다시 빌드한다 (AMB-040-6 Resolved, 2026-10-16).
- `game_info.players`는 시점 플레이어와 실제 상대(리플레이의 다른 활동 플레이어) 두 명만 id 순으로 담고, `privileged`·`result`도 그 상대 기준이다(011-R10). 헤더에 빈 칸·활동 없는 칸이 있는 게임에서 상대가 실행마다 달라지던 문제(적 종족 feature·privileged·승자)를 고쳤다. schema 4 (2026-10-17, 위임 결정).

## Acceptance Criteria
- 040-AC1: 파서가 샘플 1,000개 리플레이를 오류 없이 파싱하고, 결과가 기존 공개 파서의 명령 수·APM과 일치한다.
- 040-AC2: 디싱크 폐기율을 리포트한다(목표 < 10%).
- 040-AC3: 액션 역변환 커버리지 ≥ 95%(031-AC3).
- 040-AC4: 데이터셋 통계 리포트를 생성한다. 맵별 TvT/TvP/TvZ 게임 수가 포함되어야 한다.
- 040-AC5: SC:R 리플레이 샘플 100개를 변환·재생해 디싱크 비율을 리포트한다. 비율이 높아서(> 30%) 대상 맵 데이터가 부족하면 사용자에게 보고하고 대응을 확인받는다.
- 040-AC6: 저장 데이터에서 생성한 feature와 재생 스트리밍으로 생성한 feature가 같은 리플레이에서 비트 단위로 일치한다.

## Risks & Open Questions
- **최근 대상 맵 리플레이는 대부분 SC:R 포맷이다.** 변환 후 디싱크가 많으면 S2 데이터가 줄어든다(040-AC5).
- 1.16.1 시대 리플레이 중 투혼과 서킷브레이커 비중이 낮을 수 있다. 맵 전략은 [041](041-imitation-learning.md)을 따른다.

- **데이터 정책 (확정 2026-10-15, AMB-040-3): 내부 학습 전용**
  - 리플레이와 데이터셋은 외부에 재배포하지 않는다.
  - 출처는 shard 메타데이터의 `src`와 `reports/dataset_sources.md`에 내부 기록으로만 남긴다.
  - 크롤링 시 지킬 것: 사이트 이용약관과 robots.txt, 요청 속도 제한(기본 1 req/s 이하).
  - 예외(2026-10-16 사용자 결정, AMB-043-1): SC:R 로컬 API 래더 수집([043](043-ladder-replay-collector.md))은 EULA 해석 위험을 감수하고 허용한다. 속도·양 한도는 043-R4를 따른다.
  - 학습된 모델을 외부에 공개하려면 그 시점에 사용자에게 다시 확인한다.

- **품질 기준 (확정 2026-10-15, AMB-040-2): 단계별 기준**
