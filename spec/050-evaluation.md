## Purpose
정책 성능을 측정하고, 체크포인트 승격과 SC:R 배포 가능 여부를 판정한다.

## 평가 스위트
| 스위트 | 내용 | 판수 |
|---|---|---|
| E-Matrix | 상대(T0 각 빌드, T1 각 봇, 각 봇의 Random 종족 포함) × 맵 2 × 시작 위치 랜덤. 상대 맵핵 버전은 제외(021-R5) | 조합당 ≥ 50 |
| E-Elo | 승격 체크포인트 간 라운드로빈 → Elo / TrueSkill | 쌍당 ≥ 20 |
| E-Regression | 고정 시나리오 통과 여부. 시나리오는 **해당 전략만 쓰는 T0 전용 봇**으로 구현한다(저그 초반 러시, 테란 드랍, 프로토스 다크템플러, 저그 뮤탈). 통과 = 승률 ≥ 50% | 시나리오당 10 |
| E-SCR-Smoke | SC:R 커스텀 게임: 내장 AI 3종족 × 맵 2 | 조합당 ≥ 3 |
| E-APM | 평균·최대 APM, 명령 분포 (**참고 통계**, 제한 없음) | 전 게임 |

### 050-R3 승격 게이트
| 조건 | 기준 |
|---|---|
| E-Matrix 최약 조합 승률 | 이전 대비 하락 ≤ 5%p |
| E-Elo | 이전 대비 +0 이상 |
| 직전 승격 체크포인트와 직접 대전 | 승률 ≥ 55% (042-AC3과 동일) |
| E-Regression | 전부 통과 |

- **구현 범위 (2026-10-17 사용자 결정, AMB-050-2)**: M6 3단계(RL 루프)는 "직전 승격 체크포인트와 직접 대전 ≥ 55%"와 "E-Regression 전부 통과" 두 조건으로 승격한다. E-Matrix 최약 조합과 E-Elo 조건은 4단계 평가 파이프라인(050-AC1)과 함께 붙인다. 그 전까지의 승격 기록에는 빠진 조건을 표시한다. 042-AC1 실험에는 승격이 필요 없다.

- **붕괴 항복 (2026-11-03, 메인 임시 결정, AMB-042-15)**: RL 학습 게임의 붕괴 항복(042-R14)은 평가 게임(이 spec의 스위트, RL run 점검 평가 포함)에 적용하지 않는다. 평가는 지금 규칙(60분 무승부, 031-R12 항복 모드)대로라 이전 측정과 비교할 수 있다. 무너진 뒤 무승부가 된 판은 run 점검에서 막음 비율(042 "러시 커리큘럼 run")로 따로 본다.

- **RL run 점검 `rush-s2` (2026-11-03 사용자 결정, AMB-042-16)**: 100만 agent step마다 rush-s1 점검 4상대(T0 `zerg_rush`, UAlbertaBot 기본 저그, Steamhammer 오버풀 변형, ZZZKBot)에 운영형(비러시) 저그 2상대 UAlbertaBot 설정 변형 `ualbertabot2hatchhydra`·Steamhammer 설정 변형 `steamhammer2hatchmuta`(2026-11-04 사용자 결정, 042 `rush-s2` 운영형 그룹 중. 출발 체크포인트 측정 승률 70%·20%)를 더해 각 10판(stochastic, 투혼, seed_base 43000). 승·패·무(Wilson 95%, 050-R2)와 막음 비율(러시 상대), 042 정찰·대응 지표(적 본진 발견 시각, 4:00·6:00까지 본 적 건물 종류 수, 첫 배럭·벙커 시각, 4:00 SCV 수)를 상대 종류(러시·운영형)별로 보고한다. 033 정찰·생존 보상(r_scout·r_survive)은 학습 전용이며 평가·승격 판정에는 쓰지 않는다(033-R1, r_win만).

- **조건 통제 러시 점검 (`rush-s5`부터, 050-R6·R7, 2026-11-05 사용자 위임, AMB-042-19)**: 원인 분석(`reports/m6_rl_rootcause.md`)에서 러시 판 결과의 큰 몫이 시드가 정하는 시작 위치(상대 첫 웨이브가 우리 본진으로 바로 오는지, 020-R21 "첫 목표 적중")로 정해지고, `seed_base + n` 점검은 시드 집합마다 적중 비율이 0/30~36/40으로 달라 run 사이·학습 조건과 비교할 수 없었다. 10판 점검은 ±30%p, 30~40판은 ±15%p라 지난 결론 대부분이 잡음 안이었다. 그래서 조건을 고정한 같은 시드 목록으로 짝 비교한다.
