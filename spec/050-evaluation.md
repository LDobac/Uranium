# 050 — Evaluation

- **Status**: Approved (2026-10-15, 2026-10-17 개정: 승격 게이트 단계별 구현 범위(AMB-050-2, 사용자 결정))
- **Related**: [000](000-overview.md), [021](021-opponent-pool.md), [042](042-rl-training.md), [012](012-bridge-remastered.md)

## Purpose
정책 성능을 측정하고, 체크포인트 승격과 SC:R 배포 가능 여부를 판정한다.

## 평가 스위트
| 스위트 | 내용 | 판수 |
|---|---|---|
| E-Matrix | 상대(T0 각 빌드, T1 각 봇, 각 봇의 Random 종족 포함) × 맵 2 × 시작 위치 랜덤. 상대 맵핵 버전은 제외(021-R5) | 조합당 ≥ 50 |
| E-Elo | 승격 체크포인트 간 라운드로빈 → Elo / TrueSkill | 쌍당 ≥ 20 |
| E-Regression | 고정 시나리오 통과 여부. 시나리오는 **해당 전략만 쓰는 T0 전용 봇**으로 구현한다(저그 초반 러시, 테란 드랍, 프로토스 다크템플러, 저그 뮤탈). 통과 = 승률 ≥ 50% | 시나리오당 10 |
| E-SCR-Smoke | SC:R 커스텀 게임: 내장 AI 3종족 × 맵 2 | 조합당 ≥ 3 |
| E-APM | 평균·최대 APM, 명령 분포 (**참고 통계**, 제한 없음) | 전 게임 |

## Requirements
| ID | 요구사항 |
|---|---|
| 050-R1 | **MUST** 평가는 결정론적 샘플링(argmax)과 확률적 샘플링 두 모드로 측정하고 둘 다 보고한다 |
| 050-R2 | **MUST** 승률에는 95% 신뢰구간(Wilson)을 함께 표기한다 |
| 050-R3 | **MUST** 승격 게이트를 정의한다(아래 표) |
| 050-R4 | **MUST** 평가 결과는 `reports/eval/<checkpoint>.md`로 자동 생성하고, 리플레이 샘플을 보관한다 |
| 050-R5 | **MUST** SC:R 배포 전 E-SCR-Smoke에서 디싱크 0건, 크래시 0건이어야 한다 |

### 050-R3 승격 게이트
| 조건 | 기준 |
|---|---|
| E-Matrix 최약 조합 승률 | 이전 대비 하락 ≤ 5%p |
| E-Elo | 이전 대비 +0 이상 |
| 직전 승격 체크포인트와 직접 대전 | 승률 ≥ 55% (042-AC3과 동일) |
| E-Regression | 전부 통과 |

- **구현 범위 (2026-10-17 사용자 결정, AMB-050-2)**: M6 3단계(RL 루프)는 "직전 승격 체크포인트와 직접 대전 ≥ 55%"와 "E-Regression 전부 통과" 두 조건으로 승격한다. E-Matrix 최약 조합과 E-Elo 조건은 4단계 평가 파이프라인(050-AC1)과 함께 붙인다. 그 전까지의 승격 기록에는 빠진 조건을 표시한다. 042-AC1 실험에는 승격이 필요 없다.

- **평가 기준 (확정 2026-10-15, AMB-050-1)**
  - 아래 초안 값을 그대로 확정한다. M5 기준선 측정 후 조정을 제안할 수 있고, 조정하려면 사용자 확인이 필요하다.
    - 승격 게이트: 최약 조합 하락 ≤ 5%p, Elo +0 이상, 직전 승격 대비 직접 대전 승률 ≥ 55%, 회귀 시나리오 각 승률 ≥ 50%
    - 평가 판수: 조합당 ≥ 50판
    - E-Regression 시나리오: 초반 러시 방어, 드랍 대응, 다크템플러·뮤탈 대응
  - E-SCR-Smoke 상대는 사람 또는 SC:R 내장 AI이고, 로컬/LAN 커스텀 게임으로 한다(AMB-000-2).

## Acceptance Criteria
- 050-AC1: 평가 파이프라인 하나로 E-Matrix 리포트가 자동 생성된다.
- 050-AC2: 000-G1~G3 목표 달성 여부가 리포트 상단 요약에 표시된다.
