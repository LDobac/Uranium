## Purpose
정책 성능을 측정하고, 체크포인트 승격과 SC:R 배포 가능 여부를 판정한다.

## 평가 스위트
| 스위트 | 내용 | 판수 |
|---|---|---|
| E-Matrix | 상대(T0 각 빌드, T1 각 봇, 각 봇의 Random 종족 포함) × 맵 2 × 시작 위치 랜덤. 상대 맵핵 버전은 제외(021-R5) | 조합당 ≥ 50 |
| E-Elo | 승격 체크포인트 간 라운드로빈 → Elo / TrueSkill | 쌍당 ≥ 20 |
| E-Regression | 고정 시나리오 통과 여부. 시나리오는 **해당 전략만 쓰는 T0 전용 봇**으로 구현한다(저그 초반 러시, 테란 드랍, 프로토스 다크템플러, 저그 뮤탈). 통과 = 승률 ≥ 50% | 시나리오당 10 |
| E-SCR-Smoke | SC:R 커스텀 게임: 내장 AI 3종족 × 맵 2 | 조합당 ≥ 3 |
| E-APM | 평균·최대 APM, 명령 분포 (**참고 통계**, 제한 없음) | 전 게임 |

## Requirements
| ID | 요구사항 |
|---|---|
| 050-R1 | **MUST** 평가는 결정론적 샘플링(argmax)과 확률적 샘플링 두 모드로 측정하고 둘 다 보고한다. 예외: 042-AC1 남은 run의 평가는 확률적 샘플링만 둔다(2026-11-02 사용자 결정, argmax가 기준선·네 run 모두 0/200) |
| 050-R2 | **MUST** 승률에는 95% 신뢰구간(Wilson)을 함께 표기한다 |

| 050-R4 | **MUST** 평가 결과는 `reports/eval/<checkpoint>.md`로 자동 생성하고, 리플레이 샘플을 보관한다 |

### 050-R3 승격 게이트
| 조건 | 기준 |
|---|---|
| E-Matrix 최약 조합 승률 | 이전 대비 하락 ≤ 5%p |
| E-Elo | 이전 대비 +0 이상 |
| 직전 승격 체크포인트와 직접 대전 | 승률 ≥ 55% (042-AC3과 동일) |
| E-Regression | 전부 통과 |

- **구현 범위 (2026-10-17 사용자 결정, AMB-050-2)**: M6 3단계(RL 루프)는 "직전 승격 체크포인트와 직접 대전 ≥ 55%"와 "E-Regression 전부 통과" 두 조건으로 승격한다. E-Matrix 최약 조합과 E-Elo 조건은 4단계 평가 파이프라인(050-AC1)과 함께 붙인다. 그 전까지의 승격 기록에는 빠진 조건을 표시한다. 042-AC1 실험에는 승격이 필요 없다.

- **붕괴 항복 (2026-11-03, 메인 임시 결정, AMB-042-15)**: RL 학습 게임의 붕괴 항복(042-R14)은 평가 게임(이 spec의 스위트, RL run 점검 평가 포함)에 적용하지 않는다. 평가는 지금 규칙(60분 무승부, 031-R12 항복 모드)대로라 이전 측정과 비교할 수 있다. 무너진 뒤 무승부가 된 판은 run 점검에서 막음 비율(042 "러시 커리큘럼 run")로 따로 본다.

- **RL run 점검 `rush-s2` (2026-11-03 사용자 결정, AMB-042-16)**: 100만 agent step마다 rush-s1 점검 4상대(T0 `zerg_rush`, UAlbertaBot 기본 저그, Steamhammer 오버풀 변형, ZZZKBot)에 운영형(비러시) 저그 2상대 UAlbertaBot 설정 변형 `ualbertabot2hatchhydra`·Steamhammer 설정 변형 `steamhammer2hatchmuta`(2026-11-04 사용자 결정, 042 `rush-s2` 운영형 그룹 중. 출발 체크포인트 측정 승률 70%·20%)를 더해 각 10판(stochastic, 투혼, seed_base 43000). 승·패·무(Wilson 95%, 050-R2)와 막음 비율(러시 상대), 042 정찰·대응 지표(적 본진 발견 시각, 4:00·6:00까지 본 적 건물 종류 수, 첫 배럭·벙커 시각, 4:00 SCV 수)를 상대 종류(러시·운영형)별로 보고한다. 033 정찰·생존 보상(r_scout·r_survive)은 학습 전용이며 평가·승격 판정에는 쓰지 않는다(033-R1, r_win만).

- **RL run 점검 `rush-s3` (2026-11-04 사용자 결정, AMB-042-17, 자문 E3)**: 출발 체크포인트(c0)와 1.5M agent step마다 학습과 동시에 T0 `zerg_rush`·UAlbertaBot 설정 변형 `ualbertabot12poollings` 각 40판(투혼 20·서킷브레이커 20), stochastic, seed_base 43000. 승·패·무(Wilson 95%, 050-R2), 막음 비율(042 `rush-s1` 정의, 리플레이 재생), 042 정찰·대응 지표를 보고한다. 10판 점검의 95% 범위(약 ±25%p)로는 ±15%p 변화를 못 봐서 판 수를 늘리고 상대를 둘로 줄였다(`reports/m6_rl_stall_advice2.md` 1절). c0 점검 포함, `rush-s2` 점검의 나머지 4상대는 뺌(학습 판 지표로만 봄, 사용자 결정 2026-11-04 확인). RL 모델 상대 판 시간 상한(042-R15)과 붕괴 항복은 평가 게임에 쓰지 않는다(60분 그대로).

- **RL run 점검 `rush-s4` (2026-11-04 사용자 결정, AMB-042-18)**: `rush-s3` 점검과 같다(T0 `zerg_rush`·`ualbertabot12poollings` 각 40판, 두 맵 20·20, stochastic, seed_base 43000, 막음 비율·정찰·대응 지표). c0는 이 run의 출발 체크포인트 AC1 `ac1-vtrace-s1/ckpt-3133569`라 같은 조건의 AC1 측정이 되고 `rush-s3` c0·c1과 비교된다. RL 러시 미니게임(042-R17, 8:00 판정)·붕괴 항복·모델 상대 판 시간 상한은 평가 게임에 쓰지 않는다(60분 그대로). 퇴보 게이트(점검 막음이 c0보다 10%p 넘게 낮으면 run 중단)와 판정 시점은 042 `rush-s4`.

- **평가 기준 (확정 2026-10-15, AMB-050-1)**
  - 아래 초안 값을 그대로 확정한다. M5 기준선 측정 후 조정을 제안할 수 있고, 조정하려면 사용자 확인이 필요하다.
    - 승격 게이트: 최약 조합 하락 ≤ 5%p, Elo +0 이상, 직전 승격 대비 직접 대전 승률 ≥ 55%, 회귀 시나리오 각 승률 ≥ 50%
    - 평가 판수: 조합당 ≥ 50판
    - E-Regression 시나리오: 초반 러시 방어, 드랍 대응, 다크템플러·뮤탈 대응
  - E-SCR-Smoke 상대는 사람 또는 SC:R 내장 AI이고, 로컬/LAN 커스텀 게임으로 한다(AMB-000-2).

- 050-AC2: 000-G1~G3 목표 달성 여부가 리포트 상단 요약에 표시된다.
