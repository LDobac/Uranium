## 9. A·B 비교에 필요한 학습량 (제안, 미실행)

사용자가 B를 골라 아래는 기록만 남긴다. 확대 효과 자체를 확인할 때 쓴다.

- 근거:
  - 같은 크기 안의 구조 비교는 1만 update에서 val 차이가 seed 잡음 수준이었다([core_ablation_pt], [model2] 7절).
  - 구조 변형 비교에서는 val 순위와 대전 순위가 반대였다([arch_ablation_pt] 3절).
  - 큰 모델은 같은 update 수에서 손실이 더 낮고 더 늦게 평탄해진다는 것이 언어 모델 규모 연구의 일반적 관찰이다(Kaplan 외 2020, Hoffmann 외 2022). 짧은 비교는 최종 차이를 작게 보여 준다. 이 모델에서 같은지는 미확인이다.
- 단계(CUDA 호스트):
  1. 지금 크기(GroupNorm 포함) 2 seed와 확대 후보를 본학습 일정의 앞 1만 update씩 돌린다. 약 1~1.5일이다.
  2. 판단: 2,500 update마다 곡선의 간격이 벌어지는지 본다. 첫 바퀴 학습 손실은 처음 보는 데이터라 val처럼 쓸 수 있다.
  3. 이긴 쪽만 본학습 전체로 이어 간다. B는 약 4~6일이다.
  4. 교사 혼합·DAgger(모델 판을 교사가 다시 레이블하는 단계) 뒤 게임 측정.
- 미결: 확대 모델의 학습률(폭이 넓으면 낮은 값이 맞을 수 있음, 낮춘 run 추가 여부), 긴 일정 앞부분 대 짧은 일정 완주 중 비교 방식, 판단 문턱.
