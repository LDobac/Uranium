# 모델 확대 B + 패치 공간 경로 줄기 (`m2b`)

spec [045](../../spec/2026_11_20_09_12_045-scaleup-b-patch-lineage.md)(Approved 2026-11-20)의 실험 리포트. 모델을 후보 B 크기로 키우고 공간 인코더 CNN을 패치 linear projection으로 바꾼 모델로 t2 줄기를 같은 단계·데이터·update 규칙으로 다시 학습한다.

- 상태: **실험 전.** 준비 단계: spec·코드·측정 정의 master 반영, B 구성 실측 끝, 표본 끝-끝(`M2B-5`) 진행 중(7절). 본 줄기는 아직 안 돌림.
- 인수인계: [scaleup_linear_spatial_handoff](../plan/2026_11_20_08_41_scaleup_linear_spatial_handoff.md)

## 1. 배경과 예상 (실험 전, 2026-11-20 10:33 작성)

### 배경

| 근거 | 내용 | 출처 |
|---|---|---|
| 덜 배움 | 본학습 끝 학습 손실 0.858 = val 0.859, 아직 내려가는 중 | [model_scaleup](../bench/2026_11_17_21_45_model_scaleup.md) 1절 |
| 크기 효과 미검증 | 크기 비교는 코어만, 1만 update뿐 | [core_ablation_pt](2026_10_24_21_29_m6_core_ablation_pt.md) |
| 교사 모드 누출 | 테란·프로토스전 12~28%가 저그용 빌드 | [teacher_leak_fix](2026_11_17_20_08_teacher_leak_fix.md) |
| CNN 사용량 | 요약 `s_pool` → 코어는 정보 안 쓰임, 위치 머리는 CNN 특징에 크게 의존 | [spatial_ablation](../investigation/2026_11_19_23_00_spatial_ablation.md) 2·3·6절 |

### 가설과 예상

| 가설 | 예상되는 관찰 |
|---|---|
| (가) 용량 부족 | 학습 손실이 내려가고, 교사 모드 누출(`zerg_build`)이 줄고, T1 봇 상대 성적이 나아진다 |
| (나) 데이터 부족 | 학습 손실만 내려가고 게임 지표(누출·T1·T0)는 그대로 |

- 위치 머리는 CNN 대신 패치 경로에서 정보를 얻어야 한다. 건물 배치 정확 칸·랠리 오차가 t2보다 나빠질 수 있다(가장 큰 위험, spec 045 위험 표).
- 학습 손실이 `m2-s1`보다 낮아도 게임이 그대로면 (나) 쪽 근거.
