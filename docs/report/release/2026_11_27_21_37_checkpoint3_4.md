# Checkpoint 3·Checkpoint 4 — 모델 2 최종 가중치와 확대 B 줄기 끝 모델

- 작성: 2026-11-27
- 계기: 사용자 요청(2026-11-27) "원래 t2 cp로 라벨링 … 지금 나온 모델도 라벨링해". 확대 B 쪽은 같은 날 사용자 선택(줄기 끝 t2b만).
- 이름: Checkpoint 2(t1, 2026-11-17)는 그대로 둔다. 모델 2의 최종 가중치는 그다음 날 t2로 정해졌다([teacher_leak_fix] 4절). 이 문서가 t2를 Checkpoint 3으로 붙인다.
- 상세: Checkpoint 3은 [teacher_leak_fix], Checkpoint 4는 [m2b_scaleup]. 이 문서는 정의·계보·결과 요약만 싣는다.
- 표기: `<shared>`는 공용 드라이브([061][s061]). 기록이 없는 값은 "–".

## 1. 정의

| 저장소 사본 | `releases/checkpoint-3/` | `releases/checkpoint-4/` |

- 저장소 사본 = 가중치·`meta.json`·`lineage.json`·`train_state.json`·설정·`MANIFEST.json`(sha256). 옵티마이저 상태는 공용 드라이브에만 둔다.
- 사본의 sha256은 원본 `manifest.json`과 일치(2026-11-27).
- 불러오기: `uranium.ckpt.load_model("releases/checkpoint-3")`(`-4`도 같음), 2026-11-27 CPU에서 둘 다 확인. 게임 plan은 공용 드라이브 경로를 쓴다.
- 모델 구조:
  - Checkpoint 3은 Checkpoint 2와 같은 모델 2 구조이고, `spatial_norm`만 더해졌다([gn_resume]).
  - Checkpoint 4는 확대 B 구조(엔티티 512·6층, 코어 1024·4층, CNN 대신 패치 linear projection, [m2b_scaleup] 2절). 다른 체크포인트와 가중치가 호환되지 않는다.
