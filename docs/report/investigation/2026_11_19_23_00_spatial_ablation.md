## 0. 배경·예상 (측정 전 작성)

CNN 역할 두 가지([032](../../spec/2026_10_15_22_24_032-model-architecture.md) §1·§2.2·§2.5):

| 역할 | 경로 | 영향받는 머리 |
|---|---|---|
| ① 요약 | `s_pool = Linear(8192→256)(flatten(S8))` → Core 입력 768 중 256(`core_skip`도 Core 입력을 받음) | 전부(행동 종류·지연·선택·대상·위치·가치) |
| ② 위치 머리 | `S8` + skip(64²·32²·16²) → 업샘플 → 128² 클릭 logit | `target_loc`만 |

- 영향 없는 경로: `terrain`(지도 채널 원본을 엔티티에 붙임, CNN 출력 아님), `outer` FiLM(stem 쪽, 그대로 둠), aux JEPA 정답(평가 지표 아님).
- 예상: ① 요약을 지워도 행동 종류 NLL은 거의 안 변함(사용자 관찰과 같음). ② 위치 머리 특징을 지우면 위치 NLL이 크게 나빠짐(위치 머리의 공간 정보 입력은 S8·skip뿐). 건물 배치가 이동·공격보다 더 나빠질 것.
- 20판 시험(`pilot/`): ① 제거 시 행동 NLL +0.002, ② 제거 시 위치 NLL +2.7. 예상과 같은 방향.

## 7. 열린 질문

- 이 측정은 **제거**이지 **교체**가 아니다. "선형 사영으로 바꾸면" 위치 머리가 같은 정보를 얻을 수 있는지는 학습해야 안다(위치 머리는 128² 출력이라 공간 특징 경로 자체가 필요).
- `s_pool` 정보가 안 쓰이는 이유: 학습이 안 쓰는 쪽으로 간 것(엔티티·terrain 경로가 같은 정보를 이미 줌)인지, `s_pool` 경로가 학습 압력을 못 받는 것인지 이 측정으로는 구분 못 함.
- `s_pool` 자체의 판·시점별 변동(차원별 표준편차)을 이번에 재지 않음 → "정보가 없음"과 "정보가 있어도 안 씀"을 구분 못 함. 학습 로그의 상수 차원 수(032-R25)는 gn 계열에서 0([gn_resume](../experiment/2026_11_17_10_05_gn_resume.md) 4절)이지만 문턱 기준이라 변동 크기는 모름.
- 다른 체크포인트(`m2-gn-t1e2` 등)·RL 뒤 모델에서도 같은지 미측정(이번은 t2만).
- 오프라인 NLL 변화가 실제 판 성적에 얼마나 이어지는지 미측정(특히 위치 머리 쪽).
- win_open MSE는 판별 CI가 넓어(±0.02) 작은 차이는 판단 불가.
