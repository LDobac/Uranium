## 발견
1. **`--logs` 상대 경로면 시작에 실패한다.** Rust Broker가 추론 서버의 모델 폴더를 공용 드라이브 기준으로 찾는다. docs 기본값 `runs/rl`도 상대 경로라 같은 문제가 난다. 지금은 절대 경로를 주면 된다.
2. **RL 프로세스의 할당 메모리는 private 최대 20~21 GB다.** 시작 후 약 6~9분 동안 늘어난 뒤 평탄해서 누수는 아닌 것으로 보인다. working set은 약 10 GB이고, 게임 수와 거의 무관하다.
3. **ROCm 구성에서는 엔트로피가 100 update 만에 꽤 줄었다** (action 0.85 → 0.58). 본 실행에서 지켜볼 항목이다.
4. **느린 추론 구성(ROCm, 결정 지연 71 ms)에서는 긴 판이 3,600초 제한에 걸릴 수 있다.** CUDA 구성 ①·③에서는 최대 728초였다.
5. **"1,000만 agent step"의 기준이 시간을 크게 바꾼다.** 지금 코드는 만든 act 호출 수(버린 것 포함)를 센다(042-R12).
