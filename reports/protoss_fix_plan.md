## 1. 무엇이 문제이고 무엇을 하나

**문제.** 경로 2 모델은 교사 혼합과 DAgger 뒤 프로토스전에서 거의 이기지 못합니다(T0 표준 프로토스 32판 승: BC 기준선 10 → 혼합 e7 2 → DAgger r1 1). 원인은 이렇습니다.

- 저그전 교사의 빌드 전체를 "교사 모드"로 통째로 배웠습니다. 교사 모드는 가스 없이 배럭 3개에서 마린을 뽑고, 벙커를 짓고, 마린 몇 기씩 공격하는 운영입니다.
- 이 모드는 적을 보기도 전인 개막 60~90초에 로비의 상대 종족 입력만 보고 정해집니다.
- 교사 데이터가 모두 저그전이라, "이 모드는 저그전에서만"이라는 근거가 데이터에 없습니다.
- 교사 자신도 T0 프로토스를 0/32로 못 이깁니다.

**하는 일**은 세 갈래입니다.

| 갈래 | 한 줄 설명 | 예상 효과 | spec |
|---|---|---|---|
| A. 자기 판 증류 | 지금 모델이 테란·프로토스를 상대로 둔 판을 다시 봅니다. 상황마다 "BC 기준선 모델이라면 무엇을 했을지"를 정답으로 붙여 다음 학습 라운드에 섞습니다. DAgger의 교사 자리에 기준선 모델을 둔 것입니다 | 테란·프로토스전을 BC 기준선 수준으로 되돌립니다. 가장 빠르고 확실합니다 | 044-R1~R8 |
| B. 새 교사 | 테란·프로토스 상대 전용 스크립트 교사를 만듭니다. 가스·팩토리·시즈 탱크 개막에, 벙커와 SCV 수리로 질럿·마린 러시를 막습니다 | 기준선보다 강한 시연을 줍니다. 개막부터 저그전 교사와 다른 빌드라 "종족마다 다른 개막"을 가르칩니다 | 022 |
| C. RL | RL에서 "참조 모델에서 너무 멀어지지 말라"는 벌점(KL)의 기준을 종족별로 둡니다. 저그전은 DAgger 모델, 테란·프로토스전은 BC 기준선입니다. 상대에 세 종족을 모두 넣습니다 | A·B가 만든 출발점에서 더 올립니다. 테란·프로토스전이 다시 무너지지 않게 붙잡습니다 | 044-R9~R11 |

**사전 예상**(측정 전 기록, 맞았는지는 라운드마다 확인):

- A 한 라운드면 T0 프로토스 승이 1 → 6~10/32로 오를 것입니다. 교사 모드 판은 30/32 → 10/32 아래로 줄 것입니다.
- 저그전은 막음 합(이른 + 늦은)이 r2 76에서 약간(0~6판) 줄 수 있습니다. 저그 교사·DAgger 몫이 59.5%에서 45%로 줄기 때문입니다.
- B는 T0 프로토스·테란을 각 70% 안팎 이기는 수준까지 만들 수 있을 것입니다. 다만 021-R8 교사처럼 조정 반복이 여러 번 필요할 수 있습니다.
- C의 효과는 불확실합니다. 이전 RL run들은 러시 방어를 거의 올리지 못했습니다(`reports/m6_ac1.md`, 042 `rush-s*`). 종족별 참조는 "올리기"보다 "무너지지 않게 붙잡기"가 주 효과일 것입니다.

## 2. 사용자 결정 (2026-11-14, 여섯 가지 모두 기본안)

아래 여섯 질문은 모두 **기본안으로 정했습니다**(사용자 결정 2026-11-14). 나머지 AMB(022-3~7, 044-2·6)도 기본안 채택을 확인받았습니다. 아래 본문은 질문할 때의 설명을 그대로 남긴 것입니다.

1. **증류 정답의 꼴** (AMB-044-1)
   - 기준선 모델은 상황마다 행동의 확률표를 냅니다. 그중 무엇을 정답으로 쓸지 정해 주세요.
   - (가) 확률대로 하나를 뽑기(기본안): 사람 데이터와 같은 꼴입니다. 평균적으로는 확률표 전체를 배우는 것과 같습니다. 손실·데이터 형식이 그대로입니다.
   - (나) 가장 높은 하나: 기준선의 "늘 가장 높은 것만" 놀이는 T0 저그 200판 0승이라 위험합니다.
   - (다) 확률표 전체: 정보는 가장 많습니다. 다만 손실을 바꾸고 학습 메모리·시간이 늘며 구현이 하루 이상 더 듭니다.
2. **증류 판: 누가, 누구와, 몇 판** (AMB-044-3·4)
   - 기본안: 041-R29 ④ 선택으로 고른 모델(지금 규칙이면 r2일 가능성이 큽니다)이 600판을 둡니다.
     - T0 표준 프로토스 240판, T0 표준 테란 120판
     - T1 프로토스(UAlbertaBot·Stardust) 120판, T1 테란(UAlbertaBot·Iron) 120판
     - 10분 상한입니다.
   - 첫 라운드로 부족하면 한 번 더(300판)까지 합니다.
   - 대안: T0만 600판, 300판으로 빠르게, r2로 바로 시작(선택을 기다리지 않음).
3. **데이터 몫** (AMB-044-5)
   - 기본안: 저그 교사 + DAgger 45%, 증류 20%, 사람 35%입니다. 이러면 전체에서 테란·프로토스전 몫이 약 26%에서 약 42%로 오릅니다.
   - 대안: 저그 교사 + DAgger 59.5%를 그대로 두고 증류는 사람 몫에서 떼어 냅니다(저그전은 더 안전, 테란·프로토스 회복은 덜 함).
4. **"됐다"의 기준과 그다음** (AMB-044-7·8)
   - 기본안: 테란·프로토스는 기존 회귀 게이트(050-R10, BC 기준선 이상)를 통과해야 합니다. 저그전은 선택 자격(TvZ 16/32 이상, 늦은 막음 24/64 이상)을 지키고, 막음 합이 선택 모델보다 6판 넘게 줄지 않아야 합니다.
   - 통과한 증류 모델은 "경로 2 수정 모델"로 따로 이름 붙여 RL 출발점으로 씁니다. 선택 모델은 Checkpoint 1 비교용으로 그대로 둡니다.
   - 대안: 벙커 조건은 기록만, 저그 허용 폭을 10판으로.
5. **새 교사의 방향과 합격선** (AMB-022-1·2·4)
   - 기본안: 질럿·마린 러시는 입구를 건물로 막는 벽 대신 벙커 + SCV 수리 + 시즈 탱크로 막습니다. 상대 본진을 찾으면 정찰 SCV가 2:40까지 머물며 생산 건물 수를 봅니다. 합격선은 T0 표준 프로토스·테란 각 64판 중 44승(69%) 이상입니다.
   - 대안: 벽(가장 강하지만 시작 위치 8곳마다 자리 표가 필요하고 실패에 약함), 합격선 40/64.
6. **RL 설정** (AMB-044-9·10·11)
   - 기본안:
     - KL 기준: 저그전은 선택 모델, 테란·프로토스전과 Random 상대는 BC 기준선입니다.
     - 상대 비율: 테란 30 : 프로토스 35 : 저그 35이고, 종족마다 T0 절반·T1 절반입니다. 셀프플레이는 없습니다.
     - 규모: 1 seed 600만 step이고, 150만 step마다 점검합니다.
     - 비교 run: 기존 042-R21 ④ AC1 비교 run(3 seed)은 그대로 두고 GPU가 빌 때 돌립니다.
   - 대안: 모든 종족 KL 기준 = 증류 모델 하나, AC1 설정(T0 저그만)에 종족별 참조만 더함, AC1 비교 run 취소.

**달력 기준 예상**: 결정이 오늘 나오면 다음과 같습니다.

| 날 | 할 일 |
|---|---|
| 1일차 | A·B·C 구현 시작, S 확정 |
| 1일차 밤 | A2 표본 → A3 판 생성 → build |
| 2일차 | 레이블 → d1 학습 → 측정 → 판정. 교사 점검 반복을 병행합니다 |
| 2~3일차 | (조건부) d2 |
| 3일차 | 교사 합격 → botgen |
| 3~4일차 | t1 교사 라운드 |
| 4~5일차 | 수정 RL과 점검 |
| 그 뒤 | AC1 비교 run |

모두 합쳐 5~6일이고, 대부분은 GPU·게임 대기와 사용자 판단 대기입니다. 교사 점검이 6회를 넘으면 B와 t1이 1~2일 밀리지만 A → C 길은 막지 않습니다.

## 5. 장비 배치 원칙

- **CUDA 호스트(이 PC)**: 학습(d1·d2·t1), 정책 레이블, RL 학습기에만 씁니다. 학습 중에는 이 장비에서 빌드·테스트를 하지 않습니다.
- **Linux ROCm 호스트 2대**: 판 생성(추론 f32 + 게임 슬롯), 측정 게임 추론, val500 채점에 씁니다. RL 동안은 게임 호스트입니다.
- **Linux CPU 호스트**: build·재레이블, 교사 점검 게임(스크립트끼리), 단위 테스트·빌드, `mix-fractions`에 씁니다.
- 순서와 무관한 작업은 장비별로 나눠 동시에 돌립니다. 사용자가 쓰겠다고 한 장비에는 허락 전까지 올리지 않습니다.

## 6. 위험과 대안

- **증류의 상한은 기준선입니다.** 레이블러(`m2-s2e2`)가 T0 프로토스 10/32라 A만으로는 그 위로 가기 어렵습니다. 그 위는 B와 C의 몫입니다.
- **저그전이 같이 내려갈 수 있습니다.** 판정에 TvZ 유지 조건을 넣었습니다. 걸리면 몫을 바꾸는 안(AMB-044-5 대안)을 보고합니다.
- **새 교사도 단조로운 "모드"가 될 수 있습니다.** 증류 데이터와 함께 쓰고, 지점마다 교사 모드 판 비율과 사람 val 종족별 NLL을 봅니다.
- **모두 실패하면 종족별 정책 라우팅**을 사용자 결정으로 올립니다. 저그는 선택 모델, 테란·프로토스는 BC 기준선을 씁니다(원인 분석 7절 C). 즉시 기준선 수준이지만 Random 상대 처리가 필요하고, RL에는 그대로 못 씁니다.
- 32판 묶음은 조건당 약 ±12%p 잡음이 있습니다. 경계 근처 결과는 판정하지 않고 보고합니다(050-R10과 같음).
