# T1 상대 RL 정체 — 자문 요약과 이후 개선 후보

- 날짜: 2026-11-03
- 배경: `t1self-s2`(셀프·스냅샷·anchor + T1 50%)에서 셀프 붕괴는 막았지만 T1 상대 승률이 오르지 않았다(학습 게임 15% → 0%, 점검 평가 출발점과 차이 없음). 사용자 요청으로 고성능 모델 자문(파일·프로세스 변경 없음)을 받았다.
- 관련: `reports/m6_t1self_stop.md`(1차 붕괴), `reports/m6_rush_ladder.md`(러시 상대 기준 측정), spec 042 "러시 커리큘럼 run (`rush-s1`)"(AMB-042-15).

## 1. 진단

| 항목 | 내용 |
|---|---|
| 승리 궤적 없음 | 4~5풀 러시를 막는 행동(입구 좁히기, 일꾼 동원, 벙커)은 여러 결정이 순서대로 맞아야 해서 무작위 탐색으로 찾지 못한다. 이길 수 있는 판이 없으니 advantage가 0에 가깝다. 해법은 탐색 강화가 아니라 과제를 쉽게 하거나(커리큘럼) 사전 분포를 바꾸는 것(시연 데이터) |
| 계산 배분 | `t1self-s2` 학습 step의 72%가 TvT 모델 상대 판, 그중 32%p가 보상 0인 무승부. T1 저그 판 첫 4분(러시 방어 구간)은 1.8% |
| 상대 성격 | UAlbertaBot 저그·ZZZKBot은 설정상 항상 4~5풀. 나머지 T1(Stardust, Iron, Steamhammer 테란 등)은 초반이 아니라 중반(8~32분)에 이긴다. 러시 방어는 저그 2종 상대의 필요조건일 뿐이다 |
| 원인 아님 | 정책 지연(5~6 update, ρ 0.96), 엔트로피, KL(정책 항의 2~4%), 가치 추정(손실 0.004~0.009), r_value 크기(T1 패배 판 평균 −4.5 × 0.05 = −0.23, 일꾼으로 저글링을 잡는 행동과 방향 같음), 관측·행동 공간(명백한 구멍 없음) |
| 현실적 목표 | GPU 하나·약 200 step/s에서 몇 주 안에: UAlbertaBot·Steamhammer 저그 50% 이상, ZZZKBot 4풀 방어. Iron·Stardust 상대는 훨씬 더 많은 계산이나 데이터 없이는 어렵다 |

## 2. 권고와 반영 상태

| 우선 | 권고 | 상태 |
|---|---|---|
| A | 러시 상대 기준 측정(이길 만한 20~70% 대역 찾기) | 끝(`reports/m6_rush_ladder.md`) |
| B | 러시 커리큘럼 run: 사다리 상대, 승률 대역 상대 선택(PFSP f_var), 사다리 비중 상향, 모델 상대 소량 유지 | 진행 중(`rush-s1`, 2026-11-03 19:17~) |
| C | 사람 리플레이의 러시 방어 판으로 BC 파인튜닝 → 새 출발점·새 KL 참조 | 사용자 결정으로 제외(2026-11-03, 준비가 애매). 필요해지면 다시 묻는다 |
| D | T0 러시 봇 보강(기억·탐색 버그 수정, 후반 전환, 난이도 조절) | 하지 않음(T0는 그대로 두기로 한 결정). 대신 무승부 문제는 붕괴 항복으로 대응 |

## 3. 보상·게임 규칙 관련 개선 후보 (모두 사용자 결정 필요)

| 후보 | 내용 | 기대 | 위험·비용 | 상태 |
|---|---|---|---|---|
| 무승부 처리 | 무너졌는데 상대가 끝내지 못해 60분까지 가는 판을 패배로 | 낭비 step 감소, "무너지면 진다" 신호 복원 | 무너졌다 회복한 승리가 패배가 됨(측정 41승 중 8판) | **반영**: 붕괴 항복(042-R14, 서플라이 ≤ 4가 120초, 3분부터) |
| 초반 생존 보상 | 3~8분 구간 우리 일꾼 수에 따른 작은 보상, 봇 판만, 상한, 8분 이후 0 | 지는 판에도 학습 신호가 생긴다 | 건물 기준으로 하면 1차처럼 수동성·건물 띄우기를 배운다 → **일꾼 수 기준**. value head가 4개 고정이라 기존 항목에 합쳐야 함(033 변경) | 후보 |
| 빌드 목표 z + r_build·r_units | 사람 리플레이 빌드 순서를 목표로 주고 가까워지면 보상 | BC의 자살 오프닝(저그전 30판 중 6~8판에서 4분 전 2번째 커맨드센터)을 누르고 촘촘한 보상이 생김 | z는 판 시작 때 고정이라 정찰에 따른 러시 대응은 못 담음. 상대 종족 키 없는 문제 해결 필요. 플러밍은 있음(`--z-table`, `uranium-train z-table`) | 후보(이전에 "리그 전에 다시 묻기"로 미룬 항목) |
| 셀프 판 길이 상한 | 예: 30분 | 모델 상대 무승부 낭비 감소 | 020 변경, 장기전 학습 감소 | 후보 |

하지 말 것(자문): KL·엔트로피 계수 조정, PPO 재검토, value 사전학습, 셀프 비중 올리기, 러시 상대 없이 T1 비중만 올리기, 중반 상태에서 시작(OpenBW 저장·불러오기 없음), 모델 구조 변경.
